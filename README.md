# VK HIG

Нативный SwiftUI-клиент для iOS 17+. Независимый проект, не официальный продукт VK или Apple.

## Запуск

```sh
brew install xcodegen
bash scripts/write_secrets_xcconfig.sh
xcodegen generate
open VKHIG.xcodeproj
```

В кабинете **вашего** VK ID приложения указаны доверенный Redirect URL `https://com.decoderdev.vkhig` и bundle id `com.decoderdev.vkhig`. Такой адрес не принадлежит приложению как домен, поэтому страница VK ID открывается во встроенном окне, которое перехватывает возврат на этот адрес.
Public client ID: `54879294`. Вход использует официальный публичный OAuth 2.1 через `ASWebAuthenticationSession`, S256 PKCE, проверку state и refresh. Client secret не нужен публичному потоку и не входит в приложение, логи или CI artifacts.

`VK_REQUESTED_SCOPES` в `VKHIG/Config/Shared.xcconfig` содержит только `vkid.personal_info` по умолчанию. Добавляйте лишь права, разрешённые вашему приложению в кабинете VK. Наличие ID/secret само по себе не выдаёт права `messages`, `wall`, `photos` и т. д. Функции с отказом API показывают ошибку и не заменяются демоданными.

## Реализованные пути

- Вход, восстановление/обновление токена и выход; Keychain; защита callback.
- Лента и диалоги с дополнительными страницами; история, отправка, устойчивые random_id, retry, reply/forward/delete.
- Сохранение черновиков и очереди неотправленных сообщений; очистка приватных локальных данных при выходе.
- Профили, друзья, заявки, сообщества, поиск, уведомления, фото/альбомы, видео и сохранённое: адаптеры официального API.
- Загрузка фото/документа в диалог через системные pickers и upload/save endpoints.
- Отправка поста и комментария, лайк; сервер подтверждает результат.
- Просмотр фотографий, AVKit при выдаче прямого stream URL либо официальный видеоплеер VK.
- Тема, разрешение iOS на уведомления, фактическая очистка URLCache, отдельные NavigationStack и deep links.

В main добавлены ветки комментариев с загрузкой ответов, поиск записей и пагинация каталогов. Аудиоплеер воспроизводит импортированные файлы, поддерживает очередь, AirPlay и управление с экрана блокировки. Звонки создаются через calls.start и открывают официальную ссылку VK; конференцию можно завершить через API. Push-уведомления исключены из этой версии по запросу пользователя.

Для каталога VK Музыки нужны музыкальные права API; для входящих нативных звонков — SDK/доступ VK. Для этой версии настройка APNs/провайдера не требуется. Добавлены реальные Stories, расширенные вложения, управление беседами/сообществами, поля профиля, сохранённое и пагинация получателей; результаты сборки и проверок записаны в `output/TEST_RESULTS.md`. Каталог audio.get включается только при фактическом grant audio. Полный экранный статус: `output/IMPLEMENTATION_STATUS.md`.

## Проверка

GitHub Actions выполняет генерацию проекта, build, unit tests и UI smoke/screenshots на macOS. Секреты не выгружаются. Матрица проверяет iOS 18 и 27; результаты и снимки сохраняются в `ios-18-test-results` / `ios-27-test-results`. Для устройства см. `docs/DEVICE_AND_VK_ACCEPTANCE.md`.

```sh
xcodebuild -scheme VKHIG -destination 'platform=iOS Simulator,name=iPhone 16' CODE_SIGNING_ALLOWED=NO test
```

До успешного CI и проверки с реальным разрешённым VK аккаунтом проект нельзя считать релизно готовым.

Музыкальный модуль адаптирован по PrivateMusic2: локальные плейлисты, мини-плеер, сохраняемая очередь, офлайн-файлы по аккаунтам, LRC/LRCLIB и настоящий эквалайзер для локального аудио. Точные ограничения и статус проверок: [адаптация музыки](docs/MUSIC_ADAPTATION.md), [результаты](output/TEST_RESULTS.md).
