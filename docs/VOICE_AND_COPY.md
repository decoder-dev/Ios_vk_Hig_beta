# UX тексты, локализация, ошибки (RU-first)

**Тон:** краткий, системный, без сленга, без «магии» и ненужных восклицаний. Локализуемые ключи для будущего `Localizable.xcstrings`.

| Key | RU | EN |
|---|---|---|
| nav.feed | Лента | Feed |
| nav.services | Сервисы | Services |
| nav.messages | Сообщения | Messages |
| nav.music | Музыка | Music |
| nav.profile | Профиль | Profile |
| search.placeholder | Поиск | Search |
| feed.empty | Здесь пока нет записей | No posts yet |
| messages.empty | Пока нет сообщений | No conversations yet |
| message.compose | Сообщение | Message |

Компоненты обязаны использовать строки через localizations; не использовать строки из фото-мокапов как источник истины. Реальные имена пользователей в screenshot only fixtures; не использовать личные данные.
