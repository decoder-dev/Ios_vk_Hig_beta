# Продукт, scope, persona, продуктовые решения

## Продукт

VK Native — самостоятельный нативный iPhone-клиент ВКонтакте. Он берёт глубину сценариев у Fenrir/Phoenix, но строится на настоящих Apple iOS API и доступных VK SDK. Название рабочего проекта условно; не представляться официальным продуктом VK или Apple.

## Пользовательские сценарии

- Появиться в приложении через безопасную авторизацию, вернуться к прошлой вкладке.
- Читать ленту, открывать пост, реакции/комментарии только при поддержке реального API.
- Читать диалоги, фильтровать и отправлять сообщения без задвоений.
- Просматривать профиль, друзей, сообщества и фотографию; искать контент и людей.
- Пользоваться музыкой/видео, если авторизованному стороннему приложению предоставлены права. При недоступности — UI честно объясняет почему.
- Управлять уведомлениями, приватностью, кешем, темой (по системным правилам).

## Навигация

Пять основных вкладок (вариант, проверяемый исследованиями на реальном устройстве): **Лента**, **Сервисы**, **Сообщения**, **Музыка**, **Профиль**. Видео открывается из Сервисов и главного поиска, при повышенной интенсивности использования допускается смена `Сервисы` на `Видео`. Друзья, сообщества, уведомления и поиск — не отдельные шестая-седьмая вкладки, а настоящие маршруты из подходящих точек. Не прятать важную функцию бесследно.

## P0, P1, P2

P0 = auth, tab/nav, feed, inbox, chat, profile, search, settings, offline/error/loading, accessibility и сборка. P1 = фото/видео/сообщества/друзья/уведомления/вложения/создание постов. P2 = обогащённые анимации, сложные интеракции, особые медиа-возможности; плеер с настоящим доступом к audio API — условно, может оказаться BLOCKED.

## Принцип честного UX

- Enabled: серверное разрешение реально проверено, действие завершается проверяемым результатом.
- Disabled: невозможно из-за отсутствующего разрешения, объяснить, как получить легальный доступ.
- Unavailable: метода нет/endpoint ограничен, не показывать фальшивую кнопку.
- Preview-only: это демо-данные для SwiftUI Preview; никогда не смешивать с продуктивным аккаунтом.
