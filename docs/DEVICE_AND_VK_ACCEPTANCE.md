# Проверка VK и устройства — версия без push

По решению пользователя от 02.11.2026 push-уведомления и APNs исключены из текущей версии. Приложение не запрашивает разрешение на уведомления, не регистрируется в APNs/VK push, не содержит push entitlement или remote-notification background mode. При запуске снимает прежнюю локальную регистрацию и удаляет собственные ожидающие/показанные уведомления. Серверные настройки провайдера не требуются для принятого объёма этой версии.

## Реальный аккаунт

1. Для VK ID приложения 54879294 должны совпадать redirect vk54879294://vk.com/blank.html и bundle ID com.decoderdev.vkhig.
2. Добавлять в VK_REQUESTED_SCOPES можно только одобренные VK права. Default — vkid.personal_info.
3. Войти через VK ID на устройстве, в настройках аккаунта открыть «Проверить доступ к VK». Проверка читает доступные разделы без вывода токена.
4. Отправку сообщений/вложений, изменение профиля, комментарии и управление проверять на собственных тестовых данных.

## Подписанная сборка на устройстве

На Mac с Xcode и выбранной командой Apple: `VK_APPLE_TEAM_ID=YOURTEAMID bash scripts/device-smoke.sh`. Для тестов на подключённом iPhone дополнительно задать VK_DEVICE_UDID. APNs-ключи, push-профили и настройка push-провайдера не нужны. Обычная подпись приложения и реальный iPhone по-прежнему нужны для физической проверки.

## Музыка и звонки

- audio.get и воспроизведение VK HTTPS-потока выполняются только с фактическим audio grant. Реальное одобрение музыкальных прав для этого приложения не подтверждено.
- calls.start/calls.forceFinish и официальная ссылка конференции реализованы.
- Для входящих нативных звонков нужен предоставленный VK iOS Calls SDK, контракт авторизации/сигналинга и разрешение приложения. Публичный @vkontakte/calls-sdk — JavaScript-пакет; VKID SDK — авторизация. Подмена ими нативного SDK не выполнялась.
- Кабинет VK ID заблокирован site-safety политикой этой среды. Права приложения и доступный партнёрский SDK не удалось проверить в кабинете. Обход ограничений и запрос в поддержку не выполнялись.

## Приёмка интерфейса

Результаты конкретных коммитов и CI записаны в output/TEST_RESULTS.md. Проверки симулятора и fixture-снимки не заменяют реальные API, VoiceOver/Reduce Motion, камеру/геопозицию, AirPlay, прерывания звука и физический iPhone.
