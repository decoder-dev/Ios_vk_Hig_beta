# Проверка на устройстве и доступы VK

Все изменения разрабатываются в main. Симуляторные результаты не заменяют проверку реального аккаунта и доставки push.

## Реальный аккаунт

1. У приложения VK ID `54707652` должны совпадать callback `vkhig://vkid` и bundle ID `com.decoderdev.vkhig`.
2. Запрашиваемые права задаются в `VKHIG/Config/Shared.xcconfig`. Добавлять можно только права, одобренные VK для этого приложения. Текущий безопасный default — `vkid.personal_info`.
3. Войти через VK ID на устройстве. В настройках аккаунта открыть «Проверить доступ к VK». Проверка читает профиль и доступность разделов, не публикует записи, не отправляет сообщения и не показывает токен.
4. Проверить чтение/страницы переписки, выбранные вложения и отправку тестового сообщения в собственный тестовый диалог; комментарии и администрирование — только в собственной тестовой группе.
5. Изменение профиля, исключение участников, назначение руководителей и удаление сохранённого требуют отдельного осознанного действия в UI. Сервер VK остаётся источником разрешений.

## Подписанная сборка / APNs

Нужны Mac с Xcode, вход в вашу команду Apple Developer и App ID с включённым Push Notifications. Секреты APNs и client secret не помещаются в iOS-приложение или git.

```bash
VK_APPLE_TEAM_ID=YOURTEAMID VK_APNS_ENVIRONMENT=development bash scripts/device-smoke.sh
```

Скрипт использует вашу локальную сессию Xcode для provisioning и сохраняет архив в `build/Device.xcarchive`. Для тестов на подключённом устройстве дополнительно передайте `VK_DEVICE_UDID`. Никакие сертификаты, provisioning profiles или архив подписанного устройства автоматически не выгружаются в GitHub.

- Debug/APNs development и Release/APNs production должны соответствовать профилю подписи и стороне провайдера.
- Включить push в приложении, дождаться статуса регистрации APNs/VK. Разрешение iOS и успешная регистрация устройства не подтверждают доставку.
- Для доставки VK должен поддерживать push этого приложения и иметь нужную конфигурацию провайдера для topic `com.decoderdev.vkhig`. Настраивается в доступном официальном кабинете/через поддержку VK; один VK ID client secret эту возможность не выдаёт.
- Проверить уведомление с другого тестового аккаунта при foreground, background и закрытом приложении; нажатие должно открывать правильный диалог. Затем проверить выход и прекращение уведомлений.

## Музыка и звонки

- При реально выданном `audio` используется официальный метод `audio.get`; воспроизведение возможно только для предоставленного VK HTTPS-потока. Без права запрос не выполняется. Нет извлечения чужих токенов или приватных музыкальных API.
- Конференции используют `calls.start`/`calls.forceFinish` и официальную ссылку входа.
- Для входящих звонков внутри приложения необходимы предоставленные VK iOS SDK, документация и разрешение приложения на соответствующий сервис. Универсальный VK ID SDK не заменяет транспорт звонков. Без этих материалов поддержка входящих звонков не заявляется.

## iOS 27

CI отдельно использует официальный runner `xcode-27`, проверяет наличие Xcode 27 и iOS 27 simulator. Сохраняет `.xcresult` и PNG-вложения UI-тестов для светлой/тёмной темы, крупного текста и сервисных экранов. Ошибка или очередь preview runner фиксируются отдельно; результат другой версии iOS не выдаётся за результат iOS 27.

На устройстве дополнительно проверить VoiceOver, Reduce Motion, клавиатуру, поворот экрана, AirPlay, прерывания звука, камеру, геопозицию и реальные API-права.
