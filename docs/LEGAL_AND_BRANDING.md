# Лицензии, приватность, бренды

1. Исходник Fenrir по README имеет учебный характер и запрет на иное использование/публикацию, хотя repo включает GPL-3.0. Используй исходники как справочный предмет анализа, но **не копируй** их код, изображения, ключи и иконки до юридической проверки и разрешения владельца.
2. Phoenix repo использует GPL-3.0: копирование его кода в закрытый проект может вызвать лицензионные обязанности. Свободные идеи и семантика UX не требуют копирования конкретного кода.
3. VK ID SDK — проверить актуальную лицензию самого пакета (официальный repo) и условия доступа к API. Не гарантировать App Store approval стороннего VK клиента.
4. Apple HIG — источник паттернов, но нельзя распространять дизайн как официальный интерфейс Apple. Не использовать Apple trade dress для введения пользователей в заблуждение.
5. Изображения из архива сгенерированы для демонстрации. Не переносить изображения пользователей, бренд-логотипы, альбомные обложки, арт и тексты чужих авторов в production без разрешения; заменять лицензированными ассетами.
6. Важные данные (access tokens, messages, media) требуют privacy-policy, безопасного хранения, удаления при logout, соответствия региональным законам, а также App Store privacy disclosures.
7. Даже если Fenrir «умеет» закрытую функцию, это не разрешает обход VK ToS/DRM/частных API.
